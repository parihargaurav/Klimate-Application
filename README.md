# 🌦️ Klimate - Weather Application

A modern weather forecasting web app built with **React**, **TypeScript**, **TanStack Query**, **ShadCN UI**, **Recharts**, and **TailwindCSS**.  
This project fetches real-time weather data and visualizes it in a clean and responsive UI.


## ✨ Features

- 📍 Search weather by city  
- 🌡️ Real-time temperature, humidity, and conditions  
- 📊 Interactive weather charts with **Recharts**  
- ⚡ Data fetching & caching using **TanStack Query**  
- 🎨 Styled with **TailwindCSS** & **ShadCN UI components**  
- 💻 Built with **TypeScript** for type safety  
- 📱 Responsive design for mobile and desktop  


## 🛠️ Tech Stack

- [React](https://react.dev/) – Frontend library  
- [TypeScript](https://www.typescriptlang.org/) – Type safety  
- [TanStack Query](https://tanstack.com/query) – Data fetching & caching  
- [ShadCN/UI](https://ui.shadcn.com/) – UI components  
- [Recharts](https://recharts.org/) – Data visualization  
- [TailwindCSS](https://tailwindcss.com/) – Utility-first styling
